
# Inventory Report Generator

## Description
A Java Maven application that reads inventory data from a CSV file and generates category-wise inventory statistics using Java Streams.

## Features
- Read product data from a CSV file
- Convert CSV rows into Product objects
- Calculate inventory value by category
- Calculate the grand total inventory value
- Display the report in the console

## Technologies
- Java
- Maven
- CSV File Handling
- Java Streams and Collectors

## How to Run
1. Open the project in Eclipse.
2. Ensure `data/products.csv` exists.
3. Run `InventoryReport.java` as a Java Application.

## Build
Run `mvn clean package`.
